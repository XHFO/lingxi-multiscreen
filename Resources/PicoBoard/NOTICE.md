# Native Pico world map

Natural Earth 1:110m world land dots, public domain. Geometry is derived from the same source as `Sources/LinxDisplayCore/CloudflareWorldDots.swift`; see `docs/CLOUDFLARE-WORLD-MAP.md` for provenance.

This bounded BWM file is shared by the firmware C renderer and native Mac preview. It is embedded as semantic geometry in Cloudflare world-map models, never as a screenshot. The original source hash and binary hash are recorded in `board-resources.json`.
