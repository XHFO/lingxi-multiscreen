# 微雪 ESP32-C6-LCD-1.3 · 实验固件

仅适用于 ESP32-C6FH4 / 4MB Flash / 240×240 ST7789V2 的上述开发板，不能刷到 ESP8266 AI Mac 或 StickS3。

官方资料：https://docs.waveshare.net/ESP32-C6-LCD-1.3/
LCD 引脚核对来源：官方 Demo.zip 的 Arduino/examples/LVGL_Arduino/Display_ST7789.h、.cpp。
MOSI=6、SCLK=7、CS=14、DC=15、RST=21、背光=22；初始化序列依官方例程。

## 当前版本：XH Multiscreen · 多屏灵犀分支 / alpha.19

alpha.19 修复网页自动保存导致选项焦点跳开：保存仅更新状态，不重建表单；自动校验不抢焦点，显式保存仍定位缺项。打印机页面新增“添加 Formlabs 云端打印机”，直接填写序列号和云端 Client ID/Secret，使用设备独立 OAuth/API。

配套 build 30 在电脑输入未变化时仅读取设备配置，不再每分钟撤销网页修改。首次同步、重启软件及电脑输入变更仍以电脑选择为准；仅在网页配置独立打印机时建议关闭电脑端自动同步。端点或打印机来源变化同时阻止旧电脑图片上传。实际设备升级和云账号认证待验收。

通用固件保留 Home Assistant、Bambu MQTT/HA、Formlabs 云端及天气，容量仍为 6 个普通实体、3 台打印机。单击 BOOT 翻页、双击详情/确认、长按设置/返回；RST 仍是硬件复位。可信同网段 STA 连接不要求 PIN，首次恢复热点无密码，联网成功显示 IP 后关闭 AP；不会在浏览器持久保存凭据。

设置支持中英、两种主数字、四档 90° 旋转、无操作或定时休眠和打印保持亮屏。本地打印卡片可选标准/超大百分比/超大剩余时间，后两者不取缩略图；两台以上自动显示总览。翻页钟使用 720ms、33ms 局部刷新，圆角粗数字时钟继续可选。网页以 XH Multiscreen 分组设置、串行自动保存及真实 RGB565 帧预览呈现；字体风格与屏幕方向是设备选项，不降级电脑端 Glass。

电脑连接后仍是一套混合轮转：本地源替换同功能卡片，其余软件功能继续推送；断开约 30 秒后恢复本地轮转，打印完成保留约 30 分钟。帧缓冲在上传失败时不可读，`/api/frame` 返回 503，而非把损坏缓冲冒充实屏。

构建/封包：`pio run -e waveshare-c6`，项目根目录执行 `node scripts/check-c6-stack.mjs`、`node scripts/bundle-c6-firmware.mjs`；配置分区不变，USB 必须使用 App 分段流程。内置 OTA 为 1,844,432B，余 121,648B；只完成编译及主机/浏览器回归，物理显示、配网、休眠、OTA 与长期运行未验收。完整记录见 `TESTING.md` 与 `docs/C6-STANDALONE-2.0.md`。

下文 alpha.4/10/11 的 PIN、热点密码、旧动画和渲染限制为历史记录，不代表 alpha.19 的当前流程。

## 2.0.0-alpha.10 独立运行与单按键菜单测试

BOOT(GPIO9)：单击下一张卡片/下一项，双击卡片详情/确认，长按约 1.5 秒打开设备设置/返回上一层。35ms 消抖，250ms 第二击窗口，长按只发一次、松手不再单击。设置中双击“配对码”生成 4 位随机 PIN，2 分钟有效，输错 5 次需返回后重开，离开 PIN 页关闭窗口。PIN 仅用于首次配对，成功即失效，不作为长期 API 密钥。RST 保持硬件复位。

- 菜单每屏最多 3 项，边框与文字标记选中，少于 3 项不填充。普通详情 30 秒闲置返回；设置/确认页不自动确认。HA/打印机详情只读，无暂停、停止或控制服务操作。
- 菜单期间只暂停这台设备的轮转，订阅仍更新。拒绝软件帧 204、保留原数据源优先级；退出增加 `view_revision`，Mac 推送最新画面，不重放旧帧。不额外分配整帧缓存。
- `/api/button` v2 提供设备身份、启动 ID、菜单标志、视图修订及仅软件内容页的翻页序号；菜单/本地翻页不会误触 Mac。RGB565 请求的 `X-Lingxi-*` 公开卡片标识用于关联同步实体，不发送凭据。
- Wi-Fi 重置默认取消，确认后只清除 STA 网络和一次性配网记录，保留配对与独立配置；没有 SSID 时停止重连，配置热点仍开启。OTA 只在 Mac 已添加设备管理中操作；USB 默认保留现有网络、不要求密码。

- `/api/info` 独立设备标识 `lingxi-esp32-c6-screen`；天气、HA 状态、Bambu 及翻页钟通过便携 C 渲染器与 Mac 共用布局和字体。
- POST `/image/rgb565`：240×240、大端 RGB565，严格 115200 字节，完整接收才显示。
- POST `/api/brightness?level=0…100`，0 熄屏。
- 本地时钟、设备状态、Home Assistant 实体、Bambu 打印状态与天气页；帧代次在重启时归零，电脑端能补推首帧。
- Wi-Fi 凭据由 ESP-IDF 保存在 NVS，代码不包含用户网络/设备配置。
- 测试配网热点 `Lingxi-C6-xxxxxx`，密码 `lingxi-c6-test`；浏览器访问 `192.168.4.1`，手工输入 2.4 GHz SSID 和密码。
- 局域网扫描或手动 IP 添加，独立 C6 能力标识。C6 已独立成设备类型，不能用 ESP8266 刷写入口。
- `/standalone` 后台及带密钥的 `/api/standalone` schema 2；电脑端可自动同步显示实体、打印机显示字段和天气设置。
- POST `/api/pair` 使用 JSON `{"pin":"0123"}`，成功返回设备已有的内部认证令牌并关闭本次配对；旧电脑保存的认证令牌仍有效。错误状态：400 格式错误、401 PIN 错误、403 未开启、410 过期、429 错误过多。未授权的设备信息、页面和日志不会展示内部令牌。
- HA 仅订阅所选实体；Bambu 直连 TLS MQTT 或使用 HA 打印机实体。容量为 6 个普通实体、3 台打印机；HA 每页最多 4 个，6 个实体按 4+2 两页轮转。
- 默认软件优先，30 秒 lease 超时后回本地；可切换本地优先。活跃打印机轮转、完成后保留 30 分钟（重启后重新查询）。
- Open-Meteo HTTPS 天气，默认 30 分钟、可设 15–180 分钟，失败退避与 NVS 最近天气缓存。
- 双 OTA 分区、带认证的 `/api/ota` 和 `/api/health`。首次迁移旧分区通过 Mac USB 刷写，分段跳过 NVS/PHY。

热点暂保持开启用于调试恢复，正式版必须使用每设备配网密钥、成功联网关闭热点、按键重新开启配网，并增加请求授权。仅在可信测试网络使用，不作为公开发布固件。

构建：`pio run -e waveshare-c6`。刷写前确认芯片型号并保留私人 4MB Flash 备份；不得将备份放进资源或公开包。

镜像 offsets：bootloader 0x0、partitions 0x8000、ota_data_initial 0x10000、firmware 0x20000。完整合并镜像中的填充不代表用户配置；USB 刷写必须使用 App 的分段流程，不能用单个 0x0 写入覆盖 NVS。

自动同步使用 Mac 已批准的打印机证书；手工配置中的“信任局域网自签名证书”会降低身份校验，仅用于可信网络。HA HTTPS 与天气 HTTPS 使用系统证书包校验。

尚未完成：alpha.4 实机长期运行、PIN 配对实际显示与错误次数验证、三路 TLS MQTT 的运行时内存峰值、OTA 断电/回滚及本地字体/颜色/旋转视觉验收。测试编译与接口通过不等于可稳定公开发布。

## alpha.11 设置页与按键稳定性

- 设置、配对、网络、设备信息及等待校时页面统一中文提示，沿用主题颜色、平滑字库、圆角容器和固定标题边距。
- 菜单选中时文本不再横向跳动；每屏最多 3 行，长列表显示页码，配对码使用原生 64px 字库。
- 显示与按键路径共享 HTTP 任务内的静态状态快照，避免双击/长按时嵌套复制 3496 字节快照引起栈溢出；HTTP 栈增加至 12KB。
- BOOT 单击翻页、双击详情/确认、长按约 1.5 秒设置/返回；RST 仍为硬件复位。取消是重置 Wi-Fi 页的初始选项。
- `scripts/test-c6.sh` 包含 1000 次设置/配对/取消/返回回归，字体检查覆盖设置页中文；固件编译后运行 `node scripts/check-c6-stack.mjs` 检查实际栈报告。软件模拟不等于物理按键或长期运行验收。

## alpha.4 共享画面与本地时钟

天气、Home System 状态、Bambu 卡片和翻页钟使用同一份 C 渲染器、240×240 布局与大端 RGB565。Lingxi Sans AA 是 Noto CJK/OFL 衍生的 2-bit 灰阶平滑字体，保留英文大小写、可变字宽与基线，不再用 8px 点阵字放大模拟。字体数据 530,036 字节，按需解压到 6,144 字节字形缓存，不增加完整帧缓冲；许可证位于 Resources/Firmware/C6_FONT_LICENSE.txt。

Mac 对这些 C6 卡片不再叠加 SwiftUI Liquid Glass；其他彩屏及 C6 的电脑专属模块保持原渲染。复杂玻璃、音乐/额度等电脑专属模块不会自动成为脱机功能，不能承诺所有电脑卡片离线复现。本地与在线共享卡片应用同一 14-bit 饱和度/对比度算法；原生时钟不校准。预览帧读取不会抢占软件 lease 或更改屏幕内容。

天气、HA、打印机只在可见字段或画面代次变化时重绘。可见内容不变的 MQTT 更新时间不触发字体解压；隐藏进度变化也不触发重绘。切页、外部新帧、部分上传失败及显示控制都会使旧画面缓存失效。

翻页钟在连续分钟切换时播放 600ms/10fps 的折叠过渡，空闲只每秒更新。切页、PIN、软件帧、亮度/旋转变化或校时跳变取消过渡；不播放过时数字。flip_animation 默认开启，配置后台及软件可关闭。

打印任务静态封面使用每台最多 80×80 的小缓存，任务键变化清旧图；原生 MQTT 可保留电脑同步的任务封面，HA image 实体可由设备获取 JPEG。暂不支持 PNG/渐进式 JPEG 或 live camera 的脱机监控流，详情状态可提示不支持或拉取失败。

## 扩展方向（未实现）

1. 设备端播放进度等更多原生渲染：时钟已实现；继续减少整帧推送。
2. BLE 配网与发现：C6 原生 BLE，无需反复切电脑 Wi-Fi。
3. 低功耗分支：联网关闭 AP、空闲背光、Wi-Fi modem sleep；LCD 开启时不能承诺电池续航。
4. 板载 microSD：离线相册、封面缓存、网络断开后保留画面；官方 SD_CS=4，与 LCD 共用 SPI，需要总线仲裁。
5. 802.15.4 / Thread / Zigbee：芯片支持，需独立固件和网关生态验证，不等于本板已成为 Matter 控制器。
6. 板载 RGB 灯：官方例程 WS2812B GPIO8，可做打印完成、番茄钟、HA 告警提示，亮度可独立关闭。
7. 外接 GPIO 按键/传感器：做实体控制或翻页分支，不挪用 RESET 作为普通功能键。

未发现板载 IMU、麦克风或触摸控制的可靠证据，不直接移植飞鼠/语音输入功能。

## 网页配置与 Wi-Fi 扫描

热点首页提供附近 2.4 GHz Wi-Fi 扫描、SSID 选择、密码输入及手工添加隐藏网络；异步扫描由 C6 无线模块执行，不更改现有网络配置。`/api/wifi/scan?start=1` 发起扫描，后续读取 `/api/wifi/scan` 获取 `busy`、`error` 与最多 12 个去重网络。网络名称仅作为文本呈现，输入密码发送后清空且不保存到浏览器。Mac USB 刷机页面另外使用电脑 CoreWLAN 扫描，并将本次选择的 Wi-Fi 凭据写入一次性预配分区；两者不能混为电脑代扫接口。

`/standalone` 提供真实表单而非 JSON 编辑：显示与轮转、HA 最多 6 个实体、最多 3 台 HA/MQTT 打印机、天气及静态封面选择。PIN 配对后才可保存；授权仅留在本次页面内存，令牌和访问码不回显，留空可保留已有凭据。修改服务器地址须重输 HA 令牌，保存使用 revision 防止两入口静默覆盖。高级配置 JSON 只读并脱敏。

页面源为 `web/standalone.html`、`web/wifi.html` 和共用 `web/portal.css`。在项目根目录运行 `node scripts/embed-c6-portals.mjs` 生成两个嵌入头文件，`--check` 检查一致性。网页支持系统浅深色、桌面/手机布局、键盘焦点和状态提示。测试方法及实机边界见 `TESTING.md`。
