# XH Multiscreen · Form Monitor C6

独立测试构建 `2.0.0-formlabs-alpha.14`，硬件为 Waveshare ESP32-C6-LCD-1.3（240 × 240、4 MB Flash）。属于 XH Multiscreen 系列，Form Monitor C6 为 Formlabs 专用监看型号。复用当前 C6 的网络、显示驱动和云端解析，不替换多屏灵犀应用内的通用固件。旧协议身份与 NVS 命名空间保持兼容，不因产品改名丢失配置。源码与主机测试随 2.0 测试分支提供，不代表正式发布或实机验收。

## alpha.14 城市天气与亮度滑块

城市输入停顿后通过浏览器 HTTPS 查询 Open-Meteo 地理编码，显示城市/地区/国家和坐标候选。选择后自动填坐标，启用天气及轮转，按原自动保存机制提交；未选城市不会将新名称与旧坐标一起保存。无结果、超时、断网有提示，支持手动坐标，中文组字、旧响应和页面离开均取消旧查询。浏览器只发送城市名，不发送设备令牌/打印机凭据。城市搜索需要手机/电脑互联网连接，设备独立查询天气。后台展示真实 `/api/health` 天气状态，区分配置保存、联网、资源等待、查询、缓存和失败；失败缓存不冒充新数据。地点改变或重新启用后首次查询立即排期，仍保留资源限制和网络失败退避。

亮度采用 0–100% 滑块，数值随拖动即时更新，松开失焦或停顿后使用原自动保存机制应用，不逐帧写 Flash。中英文、手机/桌面及键盘调整均保持一致。Wi-Fi 配网页只内嵌其使用的翻译词典，保持现有分区和身份不变。软件与浏览器模拟测试不代替实际小屏亮度/网络天气验收；不自动刷设备、不发布。

## alpha.13 打印机状态布局

三种卡片统一计算任务、主体、进度条与底部详情的空间；长名称/任务省略，主数字依据实际可用高度调整，图片不再强制占用最小大尺寸。错误详情优先且为橙色，最多四行底部信息；无有效时间不生成虚假的零分钟。

空闲/待机页用橙白像素打印机图标与“空闲中 · 等待新任务 / READY TO PRINT”，不显示旧任务、旧进度、旧剩余时间或层数，可保留材料。离线页提示检查连接，不展示旧打印详情。错误、暂停、完成及取消在没有主数据时用相应状态图形，其他缺失进度/时间仍保留既有等待图标。关闭顶部状态或错误文字后，真实状态、连接、错误或完成变化仍刷新主体；不额外查询云端，不增加全屏缓冲或持续动画。

布局测试从实际 RGB565 绘制调用记录区域像素归属，覆盖中英文、像素/平滑数字、三种样式、长文/图片/隐藏项、最多四行详情、两台/三台总览，并检查内容重叠、裁切和缓冲区边界。PNG 来自软件渲染，不代表 LCD 真机视距验收。本次不自动刷写、不部署网站、不推送 GitHub。

## alpha.12 普通打印机中的固定演示状态

不再提供独立演示开关、演示预览选项或临时 page 30。添加普通打印机时，序列号输入以下严格匹配的保留代码；无云端凭据也可保存。

| 序列号 | 固定状态 |
| --- | --- |
| `;;tex_1` | 空闲，进度 / 剩余时间未知 |
| `;;tex_2` | 打印中，74%，剩余 42 分钟，888 / 1200 层 |
| `;;tex_3` | 已完成，100%，1200 / 1200 层 |
| `;;tex_4` | 出错，32%，384 / 1200 层，剩余时间未知 |

这些配置与普通打印机共用三个槽位，支持改名、删除、启用、轮转与卡片样式，重启后恢复；两台以上自动加入总览。详情及总览始终标记 DEMO，不代表真实云端连接。固定数据不随时间变化，不递减剩余时间、不生成滚动结束时间、不请求 OAuth、设备状态或图片，也不视为休眠策略中的真实打印任务。后台输入代码后禁用并清空凭据字段，切回真实序列号后重新启用字段。只有四个精确代码免凭据；相似代码、无效真实信息不能回退为演示。真实设备原有凭据验证、缓存隔离与更新频率不变。

配置、静态快照、预览轮转、总览标记及真实设备回归已覆盖软件测试；仍需用户刷入后检查实际屏幕、重启持久化与真实 / 演示混合使用。保持原分区、NVS 命名空间及设备身份，不自动刷写、不公开发布。

## alpha.11 设备优先引导

首次引导在小屏上进行，二维码页沿用时钟与打印卡的橙黑主题、像素工具字体、方形边框和分隔线。01/02 为连接热点或备用配网页，02/02 为真实联网后的 LAN 后台。二维码始终黑白、整数像素、四模块静区，不加动画或主题色。实际 SSID / IP 用橙色突出。引导期间不自动休眠，低亮度设置临时保证可读；退出恢复原亮度。

后台删除首次教学面板，只保留 Wi-Fi 表单、联网后的实际后台链接及设备设置。语言切换、独立打印机名称/序列号/云端凭据、天气城市/经纬度/间隔均保留；天气沿用 Open-Meteo，不添加任意来源 URL。LAN 地址变化会重绘二维码，断网时隐藏旧二维码。保存打印机或启用天气后可结束引导，也可双击 BOOT 稍后配置。

实际 C 显示程序输出中英文六张 RGB565 图，检查主题、完整静区、矩阵像素和独立解码。仍不代替 USB 重启、手机相机扫码、门户自动弹出与实机云端验收。保持相同分区，不整片擦除、不自动刷写、不发布。

## alpha.10 首次配置引导

首次启动 / 实体重置 Wi-Fi 后显示当前 `XH-Multiscreen-xxxxxx` 热点的标准 Wi-Fi 二维码。扫描连接后，AP 专用 DNS 与 HTTP 门户帮助手机发现配网页；不能保证所有手机自动弹出。BOOT 单击切换网页二维码，手动入口为 `http://192.168.4.1/`。DNS 仅绑定 AP、只接受 AP 子网来源，LAN 的 404 不被截获；不拦截 HTTPS、不伪装已接入互联网。Wi-Fi 写入要求设备同源页面和专用请求头。

提交 Wi-Fi 不等于连接成功：后台有界轮询真实联网状态，取得实际 LAN IP 后显示交接步骤和新链接。成功后屏幕自动换成 `http://实际IP/standalone#printers` 二维码，热点延后 12 秒关闭，手机需切回同一 Wi-Fi。单击查看指引、双击稍后配置；第一次添加并保存打印机后结束首次引导。没有打印机的已配网设备每次启动会提供一次指引，不改配置结构或额外写 NVS。

后台与 Wi-Fi 配网页顶部均提供地球图标及永久双语 `语言 / Language`，中文和 English 使用各自语言名称。切换立即改变网页固定文案，并独立保存设备屏幕语言；旁边显示同步进度、成功或失败重试，不被旧轮询覆盖。已移除“屏幕与轮转”里的重复语言选项；未填完的打印机凭据、无效表单、姓名/Secret 草稿不会阻止语言保存或被重建清空。alpha.11 已移除长篇网页首次引导，配置字段和连接状态保留。密码不回显、不留在浏览器，失败可重试。

本地网页安装器完成所有文件回读后，显式发送 DTR=false / RTS reset 脉冲并释放串口；不使用 esptool-js 0.5.7 缺少 RTS assertion 的 hard_reset。这里仅确认重启请求，仍需真机验证 USB 重启、热点扫码/门户和首次云端配置。刷写前拆除背后两组 GPIO 之间的杜邦线。

## alpha.9 打印机总览

保存的打印机数量达到两台时自动显示“打印机总览”，加入自动轮转并出现在网页预览卡片中；减少到一台时自动移除。每台独立显示用户名称、实际状态、细进度条及百分比，两台/三台采用不同的行高，不显示缩略图。总览不受单台详情的隐藏选项或单卡轮转开关影响；已禁用设备标注“已禁用”，未知进度显示 `--%`，不填零。离线时标注离线；存在有效缓存进度时保留最近进度，不伪装成实时在线。alpha.12 的特殊序列号演示属于普通配置，因此计入设备数量。

使用现有状态快照，无额外云端查询或图片下载，无第二个帧缓冲；仅显示字段变化时重绘。两台/三台、双语、禁用/离线/未知进度、删除后移除及逐行隔离均有自动测试；测试预览属于样例数据，真实多打印机联网与 LCD 物理可读性仍需实机确认。

## alpha.8 休眠视觉提示

超大百分比与剩余时间样式在原“等待进度 / 等待时间”位置改为居中的月牙与 Z 图标，以休眠视觉表达等待状态。直接使用几何像素绘制，不依赖特殊字符、语言或数字字体，不增加图片缓存或定时刷新。真实打印状态、离线提示及已完成文字保持不变；该图标不代表固件已经确认打印机处于真实低功耗状态，也不改变休眠策略。

## alpha.7 打印机独立卡片样式

“打印机 → 卡片详细选项 → 卡片样式”提供标准、超大百分比及剩余打印时间三种显示。样式按打印机身份保存，重排不会串扰；未指定样式的旧配置保持标准显示。两种新样式隐藏任务图片并停止相关图片下载，不改动原来任务封面显示选项。切回标准时恢复该选项。主数值使用全局像素/平滑风格，其余信息按显示选项保留；任务名使用单行省略，辅助信息隐藏后让出主数字空间。

超大百分比始终显示真实进度；剩余时间始终显示剩余时长，不受“预计结束时间”选择影响。剩余时间在缓存状态上按经过的时长递减，但只在显示分钟变化时重绘，不增加云端轮询频率。未知数据使用等待提示，完成时显示已完成，不把未知时间当作零。详情内暂时不可用的显示选项变灰，不清除已保存值。临时演示卡片使用首台打印机的已保存样式，仍不写入真实打印数据。

## alpha.6 数字风格与后台层级

网页“屏幕与轮转 → 主数字风格”可选择“像素 · 复古仪表”或“平滑 · 航天曲线”，自动保存并应用到设备，重启保留。仅改变翻页钟小时/分钟、天气温度与打印百分比；秒数、日期、单位和正文不变。旧配置默认保留原有像素数字。平滑数字使用原创曲线路径与 4-bit 覆盖度，重平衡数字底部、上下腔体与重心，不附带商业字体或 NASA 标志资产。

网页以品牌、型号、分组导航和页标题分层，外观切换位于页头；浅色采用冷灰中性底，深色采用石墨灰，橙色用于选中项和主要操作。Wi-Fi 页保持手动连接流程，不自动提交网络信息；移动布局使用可横向滚动导航与换行页头，预览仍直接读取真实设备 RGB565 帧。

## alpha.5 网页与临时演示

参考 Formlabs Mobile 官方 App Store 截图的浅色圆角面板、内容优先及少量橙色强调，增加浅色、石墨深色与跟随系统三种网页外观；网页外观只改变浏览器，不改变设备的橙黑像素界面。设备网页、Wi-Fi 热点与 hostname 使用 XH Multiscreen 命名。

普通设置采用约 800 ms 防抖自动保存并立即应用，失焦可提前保存；中文输入法组字期间不发送。保存串行执行，保存过程中新增的输入、名称与 Secret 草稿不会被旧响应覆盖；成功后采用最新配置版本继续保存，未变化的内容不重复写 Flash。409 冲突停止自动写入，需重新读取；网络或校验失败保留修改，提供“立即保存 / 重试”。Wi-Fi 切换与 OTA 仍需主动提交和确认，避免自动保存引发断网或刷写。显示设置变更不重新启动 Formlabs 云端查询；真实来源、凭据、图片或天气查询参数变更仍重新配置网络源。有效的临时预览页面在设置保存后保持显示。

历史 alpha.5 使用独立的临时演示卡；alpha.12 已删除该入口与渲染分支，旧 `card=demo` / `card=demo_off` 请求返回 409。演示状态现在仅从普通打印机序列号进入，网页预览仍读取设备真实帧。

## 功能

- 设备独立联网校时；分钟翻页采用 720 ms 缓动、折页阴影、局部 LCD 刷新，目标约 30 FPS；空闲 1 Hz。动画可关闭。
- 天气卡片：温度、天气图标、城市、湿度及风速。默认每 30 分钟查询，配置范围 15–180 分钟；失败退避、保留缓存。湿度/风速缺失时显示真实低温/高温，不填示例数据。
- 同时配置最多 3 台 Formlabs 打印机。每台独立序列号、名称、凭据、任务及缩略图缓存；同账户复用内存中的 OAuth Token，逐台查询，避免多路 TLS 同时挤占内存。
- 打印中约 30 秒更新，空闲约 120 秒；支持任务名称、状态、进度、剩余时间或结束时间、层数、材料及任务封面。完成任务保留至下一任务替换。
- 支持逐台启用、删除、改名、加入轮转；这里的“管理”为监看配置，不包含暂停、取消等打印控制。
- Bambu MQTT、Home Assistant 订阅及摄像头网络任务不运行。电脑画面推送不会抢占显示。
- Wi-Fi 配网、固件层四档旋转（0° / 90° / 180° / 270°）、亮度及 OTA 接口保留。BOOT 单击翻页、双击详情/确认、长按约 1.5 秒进入设置/返回；RST 是硬件重启，不是交互键。
- 自动休眠默认关闭，可选择无操作 1–120 分钟或每日时间段（支持跨午夜）。默认打印中保持亮屏；设备菜单打开及联网交接期间不休眠。休眠仅关闭背光与画面刷新，保留联网和数据查询，不是深度休眠。未校时不会进入定时休眠；第一次 BOOT 手势只唤醒，定时休眠中手动唤醒暂时保持所设无操作时长。

## 网页设置与真实预览

联网后打开 `http://设备IP/standalone`。快捷导航对应预览、打印机、翻页时钟、天气、屏幕、自动休眠及固件更新；配网页联网成功后转向实际局域网 IP，不依赖 `.local`。网页采用与设备一致的橙黑主题，中文文案使用统一的配置与状态术语。

网页预览直接读取设备 RGB565 帧缓冲，并按设备实际旋转角度显示，不使用模拟界面或示例叠图。每 3 秒单请求采样；画面未改变时返回 204，页面隐藏或关闭时停止读取。休眠中显示最后画面，读取预览不唤醒设备；预览用于核对布局，不模拟连续翻页动画。

选择时钟、天气或已启用的打印机后，点击“切换设备画面”可让真实屏幕临时显示对应卡片 90 秒，之后恢复自动轮转；也可手动恢复轮转。该操作不保存配置，设备设置菜单打开时会拒绝切换，避免干扰实体按键操作。未保存的表单修改不会改变预览角度或新增预览设备。

网页“屏幕方向”提供四档角度；设备长按 BOOT → 屏幕显示 → 屏幕方向，每次确认增加 90°。自动休眠的简易切换位于同一设备菜单，时段、时长与打印亮屏规则在网页“自动休眠”中配置。

## 独立性与隐私

项目身份 `lingxi_c6_formlabs`，设备身份 `lingxi-c6-formlabs-monitor`，配置命名空间 `form_monitor`，天气缓存 `form_weather`。通用 C6 的 `standalone` 配置不会被覆盖或自动导入。

天气默认关闭，位置和打印机凭据默认空。启用天气时，用户配置的经纬度会发送至 Open-Meteo；打印机凭据仅发送至 Formlabs 授权服务，图片下载不携带跨域 Bearer Token。网页不回显 Secret，也不使用浏览器持久化存储；设备 Flash 保存配置，LAN HTTP 只适合可信局域网，并不提供加密存储或传输保证。

首次配置时连接 `XH-Multiscreen-xxxxxx`（仅 2.4 GHz），打开 `http://192.168.4.1/`。联网后热点关闭，在屏幕或路由器查看 IP，再打开 `http://设备IP/standalone`。本机名不是 mDNS 服务，不保证 `.local` 可解析。

## 视觉规范

支持简体中文 / English，默认中文。设备长按 BOOT → 屏幕显示 → 显示语言，双击立即保存并切换；网页顶部唯一的 `语言 / Language` 入口会自动保存并同步小屏，Wi-Fi 配网页也使用相同机制。重启保留，打开网页时读取设备语言。旧配置缺少语言字段时正常恢复为中文；不修改用户设备名、任务名、材料名、城市或 SSID。

专用 `/api/language` 只接受 `{revision, language}`，使用配置版本防冲突，已有语言不重复写入 Flash；写入失败保留原设置。严格校验同源、设备 Host、自定义请求头及实际接口/子网，只允许配置 AP 来源或原 STA-only LAN 边界，AP 不因此取得 LAN 配对令牌。仅刷新菜单、卡片和当前二维码语言，不重启云端订阅。检测其他页面改动时保留草稿、暂停整表单自动保存，要求重新读取，避免把旧草稿覆盖到新配置。

仅专用构建采用工业终端样式：纯黑底、`#FF5500` 高亮、白色主文字、`#999999` 辅助文字、`#333333` 分隔线；16 px 主内边距。RGB565 量化后对黑底的实测数学对比度分别为 6.55:1、21:1、7.52:1。

英文、小数字、标点使用自带 5×7 位图字形，以整数像素块绘制，无字体抗锯齿；翻页钟、温度、进度的大数字共享原创 12×20 粗体点阵字，切角外轮廓、粗笔画，避免把小字简单放大成空心方块。中文保留原有可再分发的平滑字体。任务、长名称自动换行或省略；菜单 3 行分页，选中行同时有橙色与独立绘制的橙色箭头，不只依赖颜色。参考图中的激光功率、扫描线、Z 高度等不是固件功能，不做虚构显示。

按 apple-design 的可读性、信息层级与动效原则复核：`typography.md › Ensuring legibility` 要求实际视距验证，`color.md › Inclusive color` 不只依赖颜色，`motion.md › Best practices` 要求动效有目的且可关闭。本设备是非触摸嵌入式 LCD，不直接套用 macOS 点字号、窗口或触控尺寸。保留像素审美；不加入 CRT 白噪、整屏闪光、持续扫描线或呼吸闪烁，以减少干扰与刷新负担。

## 构建与检查

从仓库根目录运行：

```sh
node scripts/embed-formlabs-c6-portal.mjs
pio run -d Tools/FormlabsC6Firmware -e formlabs-c6
bash scripts/test-formlabs-c6.sh
bash scripts/test-c6.sh
```

构建文件位于 `.pio/build/formlabs-c6/`。OTA 使用 `firmware.bin`，必须匹配专用项目名；不同项目的 OTA 会被拒绝。首次由通用版切换到专用版需 USB 写入。

USB 首次安装前确认芯片、Flash 容量、分区和完整备份。兼容当前分区表时，只需写 `ota_data_initial.bin` 到 `0x10000`、`firmware.bin` 到 `0x20000`；不得以整片擦除或从 `0x0` 写入合并镜像来保留配置。完整回退备份含用户数据，不应放入固件包或公开仓库。

## 验证边界

alpha.5 最终构建静态 RAM 为 91,428 B，Flash 1,898,187 / 1,966,080 B（96.5%），模拟封面只增加 3,200 B 固定缓冲，没有第二个全屏缓冲。专用版自动测试及通用 C6 回归通过；实际网页保存响应合并测试覆盖保存期间新增名称和 Secret 草稿、版本续接、无变化不写入、IME 与冲突停止。

alpha.5 已 USB 刷入测试设备，写入哈希验证通过；事前校验私密 4 MB 完整备份及分区表，只写程序/OTA 选择分区。LAN 检查更新后全部用户配置逐字段相同；虚拟设备未授权请求拒绝、开启/关闭、重启清除及真实配置不变通过，最终保留临时演示开启。网页实测连续修改亮度自动应用，随后恢复用户原值，其余字段未改变。浅色、深色及 390 px 宽度均检查，无横向溢出；安全截图见 `artifacts/formlabs-alpha5/`。正文、辅助文字与强调色在两主题卡片底色上对比度为 6.21:1–15.73:1。

本次演示数据与封面均为模拟，不证明真实打印机云端访问、真实缩略图成功或实体屏幕的物理观感。设备实际 RGB565 帧读取成功，LCD 目视效果仍由用户检查。现有 OTA 写入校验拒绝问题未在本轮修复；本次采用 USB 更新，不宣称 OTA 已验证可用。
