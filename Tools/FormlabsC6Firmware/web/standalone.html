预览说明

预览直接读取设备画面，每 3 秒刷新。切换画面会在设备上显示 90 秒，不修改已保存设置。

Formlabs 打印机

支持独立监看最多 3 台打印机，通过 Formlabs 云端 API 更新任务信息。仅提供状态监看，不执行暂停或停止打印等操作。

打印机总览

添加两台或更多打印机后，自动显示总览卡片并加入轮转，集中展示各台设备的状态与进度。

演示序列号

添加打印机时，序列号填入 ;;tex_1（空闲）、;;tex_2（打印中）、;;tex_3（已完成）或 ;;tex_4（出错）。无需云端凭据；作为普通打印机保存、轮转并加入总览，数据固定不更新。最多同时添加 3 台，可移除后更换状态。真实序列号仍需有效凭据。

获取云端访问凭据

在 Formlabs Developer Platform 创建应用，填写 Client ID、Client Secret 和打印机序列号。凭据按打印机独立保存，同一账户可复用。已保存的 Secret 不回显；留空保留，变更序列号或 Client ID 后需重新填写。

翻页钟

设备自行校时与渲染。只在分钟变化时播放约 720 毫秒的折页动画，空闲每秒刷新。

中国大陆使用 28800。设备未联网校时时会显示等待校时。

天气

手动设置经纬度

启用后会将所填经纬度发送至 Open-Meteo 获取天气，默认每 30 分钟更新。失败保留最近数据并退避重试。

屏幕与轮转

仅影响翻页钟主数字、天气温度和打印进度百分比。其他文字保持不变，选择后自动保存并应用。

仅轮转勾选的时钟、天气与打印机卡片；打印机空闲或离线时仍保留卡片，便于检查连接。已完成任务保留至下一项任务。

BOOT 单击翻页，双击详情或确认，长按约 1.5 秒进入设置或返回。RST 只用于重启。

自动休眠

休眠时关闭背光并暂停画面渲染，网络连接与数据更新保持运行。按 BOOT 唤醒；定时休眠期间，手动唤醒后保持所设无操作时长。休眠时段使用设备时区，支持跨午夜；开始与结束时间不能相同。

固件更新

只选择本专用版的 OTA .bin 文件。普通 C6、ESP8266 或其他开发板固件会被拒绝。更新保留 Wi-Fi 与设备设置。

这是独立测试分支，不替换多屏灵犀应用内置的通用 C6 固件。配置保存在这台设备内；云端授权仅在内存中缓存。
