# 多屏灵犀 2.0 开发进度

更新日期：2026-10-27。当前 macOS App：**2.0.0 测试版 build86**。

## 本次同步

从早期 build31 开发基线同步完整的本地开发进度，包含 Pico 原生管理、Cloudflare 数据源、Grok Bot 集成、中英文本地化，以及 build75–86 的中控面板。稳定分支和正式 Release 不在本次更新范围。

### 中控面板

- 设备与数据源统一网格，支持添加／隐藏卡片、拖动排序、跨组移动和自定义分组。
- 1×1、2×1、1×2、2×2、2×3 尺寸；大卡跳过的空格由后续可容纳的小卡回填。拖动根据实际网格位置求解最近可达落点，不承诺任意坐标固定。
- 小窗口紧凑适配，大窗口利用可用宽度；保存的尺寸不因临时窄窗口而丢失。
- 侧栏收起后保留顶部导航、添加、外观和设置；设备详情按侧栏状态使用悬浮或常规工作区，并持续显示设备预览。
- 原生 Liquid Glass、主题一致的浮层背景、圆角裁剪、减少动态效果与减少透明度适配。
- Pico 预览使用官方外壳，独立合成当前画面，支持横竖屏；无可用画面时明确占位。

### 数据源与设备内容

- 正在播放：封面取色、光晕、进度及上一曲／播放暂停／下一曲。
- Home Assistant：选定中控实体，支持实体按能力显示控制按钮，校验数据来源并拒绝过期回包。
- 打印机：依照真实可用数据区分摄像头快照与任务封面，多尺寸适配。
- Cloudflare：共享数据源添加与 Token 权限引导，显示设置与账户连接分离，全球热区、趋势、地区排行及中英文／域名大小写选项。
- Pico：原生图书／字体／笔记库、应用与画稿管理、16 灰阶横竖画板、共享壁纸、锁屏配置及固件流程，详见专门文档。
