# 多屏灵犀 1.5.5

1.5.5 重点加入彩屏 Liquid Glass 渲染、AWTRIX NG 管理与 Beta 阶段的 M5Stack StickS3 蓝牙控制器，同时改进智能轮播、正在播放、macOS 27 兼容和多设备推送。

## Liquid Glass 彩屏渲染

- 外观设置新增“经典 / Liquid Glass”选项，默认保持经典模式。
- Liquid Glass 使用 SwiftUI 合成最终图像，软件预览与设备实际推送共用同一张画面。
- 灵犀68 与 AI Mac 彩屏可使用新效果；口袋先知、摘录墨水屏与 Emoji 壁纸保持经典显示。
- 正在播放的两种强调色都从专辑封面独立采样；深色封面会自动选择浅色时间与日期，次强调色优先保留小面积异色。
- 自定义壁纸 Pixel 时钟不再出现多余的整块玻璃底框。

## AWTRIX NG

- AWTRIX NG 成为独立受管设备，可添加、重命名、停用、删除并按每台设备隔离设置。
- 侧栏显示设备实际应用；应用设置可读取文本、数字、滑块、开关、颜色和选项等字段。
- 卡片管理支持显示/隐藏、轮换、拖拽排序、立即显示与菜单栏快捷操作。
- 实时预览使用 32×8 最近邻放大与自适应像素间隙，更接近真实 LED 点阵。
- 内置“灵犀文字”与 Home Assistant 实体卡片；中文由本地点阵字库编码，纯英文使用 AWTRIX 原生字体。

## M5Stack StickS3 控制器（Beta）

- 该板块在软件中明确标记为 Beta，适合尝鲜和反馈，不视为稳定设备功能。
- 设备管理内置完整 ESP32-S3 固件与一键刷写，会验证固件完整性、筛选原生 USB 串口、显示刷写进度并在完成后开始蓝牙扫描。
- 统一卡片主菜单提供 Vibe Coding、多屏设备、Home Assistant 与 Mac 快捷键，列表每页最多三张卡片。
- 正面 A 键用于确认和下一项，B 键用于返回；摇一摇可执行翻页、Home Assistant 控制或输入清空。
- 多媒体卡将上一曲/播放暂停/下一曲与音量减/静音/音量加整合为两张组合卡，直接通过 BLE HID Consumer Control 发送。
- 支持按住说话式输入快捷键、纯修饰键组合、自定义快捷键、蜂鸣器开关和重新配对引导。
- 飞鼠指针按类似 LG 电视飞鼠/激光笔的相对位移逻辑工作，支持重新居中与临时脱开。
- 固件采用局部刷新、空闲降频、更低 BLE 射频占空比、提前调暗与息屏，并修复特殊符号、充电图标和交互闪烁。

## 智能轮播、播放与多设备

- 歌曲切换时，已在轮播池中的“正在播放”会立即优先显示；停止播放后释放权重并恢复原页面。
- 打印机卡片自动跳过空闲和离线设备；多台打印机正在工作时按顺序切换，打印完成后继续保留约 30 分钟。
- 加快 Music、Spotify 与 MediaRemote 的正在播放识别，合并并发取样并把歌词查询移出封面刷新链路。
- AI Mac 系统监控可独立选择 CPU、内存、磁盘、网络和运行时间；新增每设备饱和度与对比度校准。
- AI Mac 和口袋先知在重启、重连后会立即补推当前有效首帧；Home Assistant 图片与打印机名称在多设备之间保持隔离。

## macOS 27 与界面改进

- 构建脚本会根据当前 Swift 工具链选择可用 SDK，隔离不同 SDK 的模块缓存，并继续以 macOS 26 为最低版本。
- 侧边栏展开/收起改为标题栏单按钮，避免 macOS 27 自动生成多余的“更多工具栏项目”二级菜单。
- 系统菜单栏中的设备与打印机项始终使用用户自定义名称。

## 安装与数据说明

1. 下载并打开 `lingxi-multiscreen-1.5.5.dmg`。
2. 将“多屏灵犀.app”拖入 Applications。
3. 本版本要求 macOS 26 或更高版本、Apple 芯片。

发布包只包含应用程序、必要资源、内置固件和第三方来源说明，不包含开发/测试期间的设备、局域网地址、Wi-Fi 信息、Home Assistant Token、Formlabs 凭据、实体绑定、图片缓存或历史画面。全新用户首次打开会进入“开始使用”设备添加引导；覆盖升级会继续使用用户电脑上已有的配置。
