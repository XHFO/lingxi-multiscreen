# C6 单按键交互（alpha.12 测试版实现）

硬件：ESP32-C6-LCD-1.3；只使用 BOOT，RST 保持硬件复位。屏幕 240×240。

## 一套手势，三个层级

| 操作 | 内容卡片 | 卡片二级菜单 / 设备设置 |
| --- | --- | --- |
| 单击 | 下一张卡片 | 下一项，末项循环至首项 |
| 双击 | 打开当前卡片的二级菜单 | 确认当前项 / 打开下一级 |
| 长按约 1.5 秒 | 打开设备设置 | 返回上一层；设置首页则返回原卡片 |

单击等待约 250ms 的第二击窗口；双击只执行一次确认，不先翻页。35ms 消抖，长按动作只发出一次，松手不再发单击。手动操作后重新计时轮转间隔。

界面使用固定的选中边框和文字，不仅用颜色识别。底部简短提示当前层级的按键含义；菜单每屏最多 3 项，滚动选中，少于 3 项不填充。进入菜单暂停这台设备轮转，退出后恢复原卡片，不改变其他设备或用户保存的轮转开关。

## 二级菜单

- 时钟：查看时间同步状态、切换已支持的显示项。
- 天气：详情、刷新（受最短请求间隔与退避限制，不连按联网）。
- Home Assistant：选择实体，查看名称、状态、更新时间；首版只读，不引入设备控制权限。
- 打印机：任务名称、进度、剩余时间、材料等已有字段；没有的数据不占空行。首版不提供开始、暂停或停止打印。
- 依赖电脑的卡片：只展示固件确实收到的详情；尚不支持的卡片显示“暂无更多详情”，保留返回入口。不把整张图片当成可操作的实体数据。

## 设备设置

1. 屏幕显示：切换 180° 翻转、翻页动画；长按返回时自动保存，无额外“结果”项。保存失败留在原页，避免丢失修改。
2. 轮询卡片：选择时钟、状态、天气、Home Assistant，以及每台打印机是否加入轮询；只修改显示参与，不删除源配置或凭据。
3. 网页详细配置：显示局域网配置地址二维码；手机连接同一可信局域网后扫描，配置天气、实体与打印机等详细内容。
4. 网络：查看已连接 SSID、连接状态、IP；“重置 Wi-Fi”单独进入确认页，默认选中取消。明确选中重置并双击确认后才清除 Wi-Fi、开启无密码配置热点；保留实体及打印机设置，不恢复出厂配置。
5. 设备信息：设备名称、固件版本、联网状态与运行时间；OTA 继续仅在 Mac 的已添加设备管理中发起。

同一可信局域网免 PIN：软件及网页自动获取设备连接会话，凭据在软件内部存储，不调用系统钥匙串。设备处于开放配网热点、尚未联网或同网段校验失败时不自动授权。此方案不提供同网段用户间的访问隔离，不适用于公共 Wi-Fi。保留内部 bearer 以避免随意跨页面请求；不将其视为抵御可信 LAN 用户的安全边界。

首次热点配置成功并获得 IP 后，设备显示“Wi-Fi 已连接”和局域网 IP，约 5 秒后关闭配网热点；单击进入卡片。已保存 Wi-Fi 时直接以 STA 启动，不常驻开放热点。USB 写入网络后联网失败，可长按 BOOT → 网络 → 重置 Wi-Fi 重新开启热点。

Wi-Fi 密码、HA Token、打印机访问码和 Formlabs Client Secret 不在屏幕显示。

## 与软件推送共同运行

- 菜单、二维码与确认页由固件渲染；Mac 正在推图或离线时都能打开。
- 菜单期间本地订阅继续更新；固件仍只保留一份完整帧缓冲，软件推图返回 204，不接收图像、不积压队列。Mac 仅暂停这台设备轮转并维持原软件租约；退出时读取新状态、推送最新帧，不重放菜单前的旧图。
- BOOT 事件带设备身份、启动标识与递增序号；内容页的翻页事件才通知 Mac，菜单选择不能误触电脑翻页。
- 返回内容页恢复当前数据源；联网时请求最新软件帧，本地时重新绘制最新状态。菜单不改变软件/本地优先级或网络订阅。
- 普通二级菜单可在 30 秒无操作后退出；设备设置和 Wi-Fi 重置确认页不自动确认，不因超时执行操作。

## 实施边界

alpha.12 取消用户 PIN 步骤，并加入返回自动保存、显示选项、轮询卡片与局域网二维码。旧 PIN 代码仅保留协议兼容，不再从当前菜单或软件暴露。正式应用与用户配置未修改。

OTA 继续只在已添加设备管理内提供。USB 默认“保留设备现有网络配置（无需密码）”；只有主动选择写入新 2.4 GHz Wi-Fi 才要求 SSID/密码，不读取 Mac 已保存的 Wi-Fi 密码。

菜单文本由现有抗锯齿中文字库渲染；每屏最多 3 行，明确选择边框和文字标记，Wi-Fi 重置默认取消。普通卡片详情 30 秒无操作返回，设备设置/确认页不自动确认。首版 HA 与打印机只读；通用图片卡片没有虚构交互数据。

验证重点：双击不额外翻页、长按松手不误触、菜单不被上传帧盖住、在线/离线一致、断网仍可进入设置、Wi-Fi 重置不清除其他配置、多设备不串扰、开机按住 BOOT 不产生操作。alpha.12 主机测试及编译不代表本版已经刷写；真机时延、二维码手机扫描、热点关闭与屏幕可读性仍需实际验收。
