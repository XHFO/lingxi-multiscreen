- 设备管理主页面分开显示添加入口与已有设备卡片，静默发现后高亮对应类型；点击卡片直接配置，无需再点编辑。
- 测试 App 独立 Bundle ID 与 `LinxDisplayBeta2` 数据目录，不导入主线设备。
- C6 NVS 配置持久化、修订号冲突保护；长按 BOOT 约 1.5 秒显示 4 位随机 PIN（保留前导零），2 分钟有效、成功后单次失效、5 次错误后锁定。通过 `/api/pair` 交换内部长授权，原配置/OTA Bearer 认证继续兼容。
- `/standalone` 热点/局域网后台同样使用 PIN 配对，共用 `/api/standalone` GET/PUT；PIN 与授权不持久保存在浏览器。
- C6 侧边栏与 AI Mac 小屏幕共用卡片管理、画板管理、屏幕控制及各功能卡片页面，增加独立的“离线与同步”页面。AI/C6 及多台 C6 按设备 UUID 隔离；精简侧栏与系统菜单同样按真实设备类型路由。
- 本地 NTP 翻页钟（分瓣数字板、中缝、铰链，保持设备本地 1Hz 走时）、设备状态页、自动轮转、BOOT 手动下一页及亮度。C6 预览使用同一套设备字形和坐标，ESP8266 时钟保留原样。
- C6 的 180° 旋转统一在固件显示层处理，覆盖电脑 RGB565 推图、本地时钟、天气和实体页；软件预览及传输图片不翻转，不影响灵犀68。方向控制接口只改变内存输出方向，自动配置同步负责持久化，避免每次推图写 NVS。
- Home Assistant：选定实体的 REST 初始读取、WebSocket 状态订阅、断线退避与过期状态提示。最多 6 个普通状态实体。
- Bambu：最多 3 台打印机；支持直连局域网 TLS MQTT，或复用 HA 的打印状态/进度/任务/剩余时间实体。MQTT 只发送只读初始状态请求，不发送打印控制。
- 默认优先电脑；心跳中断 30 秒后切回本地。可在设备设置选择优先本地数据；本地无可显示页时允许软件接管。
- 打印中、准备中、暂停的打印机参与轮转；完成后保留约 30 分钟，重复完成状态不会延长窗口，多台工作打印机依次轮转。
- 天气使用 Open-Meteo HTTPS，默认 30 分钟一次，可调 15–180 分钟；失败至少退避 5 分钟，保留最近缓存。电脑推送与 C6 离线天气页按 WMO 天气类型显示图标及天空背景：晴天采用天蓝渐变、暖色太阳与柔光，多云沿用蓝天并增加白云层，阴雨、雾、雪与雷雨使用对应天空氛围。不随电脑深色模式将晴天改为黄棕色；两端共用 sRGB 天空色表。墨水屏保留图标与文字并使用高对比灰阶，不引入天气动画或额外联网刷新。
- 天气质感：太阳采用渐亮球体，云层有柔和高光、冷色阴影及远近层次；温度使用更清晰的主视觉字重，正文保持安静背景。长屏太阳不被拉伸，窄屏温度不省略成“2…”。C6 本地采用轻量静态光影与 RGB565 有序抖动，无额外背景纹理；天气内容不变时复用画面，切回页面、方向/亮度改变、上传中断或数据变化时重新绘制。
- Mac 的天气内容页覆盖键盘、口袋先知、摘录、AI Mac、C6 与 AWTRIX；M5 控制器尚未增加天气内容页。
- 内置 C6 完整 USB 镜像与 OTA 镜像、哈希及芯片校验；USB 分段刷写跳过 NVS/PHY，OTA 使用双应用分区与回滚。
- USB 刷机可一并预配置 Wi-Fi：点击扫描读取电脑附近的 2.4 GHz 网络，选择 SSID 后输入密码，也可手工填写隐藏网络；不支持 5/6 GHz。macOS 若要求定位权限，仅用于读取 SSID，不启动定位、不获取或上传地理位置，拒绝后仍可手填。
- Wi-Fi 凭据仅写入本次 USB 操作的独立 4KB 临时区（0x3f0000）；固件校验后导入 Wi-Fi NVS 并清除临时区，不覆盖配对与离线配置。Mac 临时目录 0700、临时文件 0600，结束或失败后删除；公共固件与日志不含 SSID/密码，OTA 不携带网络凭据。

限制：C6 配置与 OTA 接口仍为带密钥的局域网 HTTP；设备存储未加密、恢复热点沿用实验密码，只适用于可信测试网络，不可暴露到公网。独立模式不建立摄像头视频流，不支持正在播放与依赖电脑的功能。HA 图片页、双图片区及 Formlabs 云 API 已在 alpha.8 扩展；不能将 MQTT 状态订阅等同于获取打印封面。以下旧版本说明记录当时实现范围，不替代顶部现状。

## 静态打印任务封面（alpha.4 实现；alpha.7 扩展见顶部）

- 同步打印机的 `show_image` 和 `image_entity`；后者只接受 `image.*` 静态任务封面实体，不接受 `camera.*`。电脑可把已有任务封面下采样为 80×80 大端 RGB565，同步到设备 RAM 缓存。保留原图比例并用黑色填充边缘，不裁切模型。
- 固件为每台已启用打印机最多保留一张图，最多三台共 38,400 字节；不分配全尺寸解码帧。缓存不写入仅 24KB 的 NVS，离开电脑后同任务仍可显示，重启后需重新通过 HA 获取或由电脑同步。
- HA 独立获取仅跟随所选静态图片实体的 `entity_picture`，地址必须和已配置 HA 完全同源；禁用重定向，不把令牌发送给外站，不把 HTTPS 降为 HTTP。使用 C6 ROM 内置 JPEG 解码器，约 4KB 工作区流式读取，限制输入 64KB、1024×1024，支持基线 JPEG。PNG、GIF、渐进 JPEG、过大图片或获取失败不会伪装成功；这些图片仍可先由电脑转为小尺寸 RGB565 同步。
- 已缓存同任务不重复下载；实体画面地址变化会使旧封面失效，变更请求至少间隔 60 秒，失败至少退避五分钟。剩余堆内存不足时让 HA/MQTT 连接优先，不再开启解码或上传缓存分配。
- HA 任务键基于任务实体的原始状态，MQTT 优先使用非零 `subtask_id`，其次 `task_id`、`gcode_file`、`subtask_name`；两端使用相同 UTF-8 FNV-1a64 键。任务变化立即隐藏旧图，增量 MQTT 报文不能把精确任务 ID 降级为任务名称。HA 若只有相同文件名、没有任务 ID，则无法仅凭名称辨别连续两次同名任务，仍需 HA 更新封面或电脑刷新。
- `POST /api/thumbnail` 必须使用配对后的长 Bearer 授权。请求头包括 `X-Config-Revision`、`X-Printer-Serial`、`X-Task-Key`、`X-Thumbnail-Width`、`X-Thumbnail-Height`。宽高为 1–80，正文严格为宽×高×2；配置修订、打印机序列标识和当前任务在接收前后各校验一次。未知打印机、禁用显示、过期修订、任务切换、半包或低内存均不能污染现有缓存。
- 原生 Bambu MQTT 报文本身没有封面图像，不能直接靠 MQTT 获取任务封面；本轮电脑上传仅支持已有 HA 静态封面来源，不暗中开启摄像头或打印机文件传输接口。

测试固件采用 4MB 自定义双 OTA 分区：NVS 0x9000/0x6000，PHY 0xf000/0x1000，OTA 元数据 0x10000/0x2000，应用 0x20000 和 0x200000，各 0x1e0000；Wi-Fi 一次性预配区 0x3f0000/0x1000。旧单分区固件首次升级需要 USB；以后可 OTA。由此前不含 Wi-Fi 预配分区的测试固件升级并使用新预配功能，也需先 USB 更新分区表。

## 自动同步：电脑只设置一次

1. 在 C6 侧边栏的卡片管理中启用功能，再在对应的 Home Assistant、Bambu 与天气页面选择实体、打印机和城市；可见画板里的对应模块也纳入同步。“离线与同步”只管理配对、同步与独立模式优先级。
2. 首次长按 BOOT 约 1.5 秒，输入屏幕上的 4 位 PIN，点击“配对并同步”。软件自动交换并按设备 UUID 保存授权到 Mac 钥匙串，不保存 PIN、不要求输入长密钥。地址以设备管理中保存的 IP 为准，防止配对与同步指向不同设备。
3. 修改后约 0.7 秒防抖同步，写入固件 NVS；断线后每分钟检查并重试，不在每次推图时重复保存。
4. 同步实体 ID/显示名称、用户打印机名、状态/进度/任务/剩余时间显示开关、天气城市/坐标/周期，以及亮度/180°/轮转周期。数据源优先级、独立模式总开关和诊断页保留设备上的选择。
5. Home Assistant 服务器地址与长期令牌优先复用设备管理中保存的连接，不要求重复填写。Bambu 可以选择 Home Assistant 实体源，使用打印状态、进度、任务名称和剩余时间实体，无需 LAN 访问码；高级手工配置也提供实体选择。本地 MQTT 必须先在 Mac 连接并确认打印机 TLS 证书；同步已批准证书，不自动关闭身份校验。HA 的主机名在 Mac 解析为局域网 IPv4；暂不支持公网、URL 子路径或独立 IPv6 订阅；HTTPS 域名证书在改用 IP 后可能不匹配。
6. 超出 6 个实体或 3 台打印机时明确提示，保留设备原配置，不静默截断。多台 C6 的同步任务、授权和状态按 UUID 隔离。
7. 关闭自动同步后可在设备后台手工管理数据，避免两个入口反复覆盖；修改冲突会返回 409 并重新读取，而不是盲目覆盖。

脱离电脑仍需 Wi-Fi 与相关服务器可访问；天气还需要互联网。打印完成窗口及普通状态缓存目前在 RAM，重启后重新查询；天气缓存与订阅配置保存在 NVS。

## 实施与合并边界

- 只针对 Waveshare ESP32-C6-LCD-1.3，保留现有电脑推图协议和 ESP8266 行为。
- 设备端新增独立配置、数据订阅、本地卡片渲染和轮转模块，避免继续将所有功能堆入 main.c。

- Mac 根据 capability 启用功能；旧固件缺少能力时保持旧行为。
- 独立模式与电脑推图模式明确仲裁，避免双方持续覆盖屏幕。
- HA 与 Bambu 分别提交、验证，后续选择性合并；本分支不自动发布或改写主线。

1. 设备配置存储、恢复默认、带认证的配置接口。
2. 本地卡片渲染、BOOT 翻页、轮转、重启恢复。
3. 一个 HA 服务器：初始状态读取、WebSocket 订阅、重连和过期标记。
4. 一台 Bambu：仅局域网 TLS MQTT，订阅状态，不发送打印控制指令。
5. 热点后台和 Mac 配置同步，电脑断开后独立模式持续运行。

## 验收

### 设备管理入口（2.0 测试版）

- 一级页分开显示“添加设备”和“已添加设备”，设备卡片点击后打开独立设置面板。
- 发现结果过滤已登记的 Home Assistant、口袋先知、小屏幕与蓝牙控制器；蓝牙重新配对流程保留扫描能力。
- 口袋先知和小屏幕扫描跳过已登记地址，并在扫描完成后再次过滤，避免扫描期间添加造成重复展示。
- 添加面板后台静默扫描，不显示独立发现列表；类型卡片以强调色边框、文字和图标提示发现数量。
- 扫描任务只属于添加窗口，关闭后取消；蓝牙尚未授权时不自动触发权限申请，交由用户点击控制器操作发起。
- 点击发现一台设备的类型卡片直接进入添加引导；发现多台时点击后选择具体设备；未发现时直接进入手动设置。
- 选择发现设备后进入添加引导，自动填写可获取的设备名称和网络地址；令牌、访问码等凭据仍由用户填写。
- 已有设备点击卡片即开放编辑，不再需要二次点击“编辑”；连接字段仍需点击“应用”才提交。
- 测试版使用独立数据目录，不重置正式版用户数据。

- 不连接 Mac 运行、断网重连、设备重启、卡片轮转和按键顺序。
- 两个配置入口 revision 冲突、认证、凭据脱敏及失败恢复。
- 至少一轮持续运行测试，记录可用堆内存、最低堆内存、断线次数和温度现象。
- 与旧电脑推图固件及旧设备配置兼容；验证回退固件与回退后的联网。
- API 成功不等于视觉验收；必须在实际屏幕检查颜色、文字和旋转。

## C6 网页控制台（本轮改造）

- 热点首页管理 Wi-Fi；`/standalone` 按连接与配对、显示与轮转、Home Assistant、Bambu Lab、天气分组，使用真实的输入框、选择器、开关和增删实体行，不再要求用户编辑 JSON。高级 JSON 仅供脱敏只读检查。
- 保留 6 个状态实体、3 台打印机的容量限制。表单覆盖翻页动画、亮度、180°、色彩饱和度/对比度、天气间隔，以及 HA/MQTT 数据源和各打印字段的显示选择。打印任务封面只接受 `image.*` 静态图片实体，不接受摄像头。
- 4 位 PIN 配对后才开放配置；内部授权只保留在当前页面内存中，不写浏览器存储。令牌和访问码不回显，成功保存、授权结束或页面离开后清空输入；留空保留设备已有凭据，但改变 HA 服务器地址后必须重新输入令牌。
- 保存携带设备修订号，冲突时提示重新读取，不覆盖另一入口的新配置；未保存修改在重新读取前给予确认。Mac 自动同步开启时明确提示以软件选择为准。
- 网页的“扫描附近 Wi-Fi”调用 C6 的真实 2.4 GHz 无线扫描接口 `/api/wifi/scan`，由低优先级任务异步执行，最多返回 12 个去重 SSID。不会主动断开现有连接或改变已保存网络；连接中、扫描失败或隐藏网络均可手工填写。此扫描与 USB 刷机页面使用 Mac CoreWLAN 扫描是两个独立入口。
- 采用系统字体、浅深色自适应、至少 44px 的常规表单控件、可见键盘焦点及页面内状态反馈；桌面侧栏在手机宽度转换为横向导航，不丢失设置项。
- 网页源文件位于 `Tools/WaveshareC6Firmware/web/`，由 `scripts/embed-c6-portals.mjs` 确定性生成固件头文件。表单模拟测试与隔离 Chrome 真 DOM 交互检查已通过，包括浅/深色 1280px/390px、320px 放大文字、凭据清空、保存、增删行、数据源切换、Wi-Fi 选择及 SSID 文本转义。浏览器网络响应全部来自测试夹具，未连接真实设备；实际无线扫描、热点浏览器操作与刷机后的联网仍须实机验收。
