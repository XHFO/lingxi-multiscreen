# 1.5.5 开发：彩屏玻璃卡片

外观 → 卡片外观 → 卡片渲染，可选经典（默认）或 Liquid Glass。
全局风格不会随设备快照切换；旧配置、未知枚举值均回退经典。

## 范围与实现

- 灵犀68 142×428、AI Mac 240×240 的软件渲染卡片及画板共用这一入口。
- 口袋先知、摘录墨水屏不进入玻璃合成器。原生桌面时钟仍由固件绘制；纯图片、无信息容器的 Emoji 壁纸保留原图。
- `ScreenRenderer` 保留现有排版与文字/图片绘制；同步作用域捕获背景、圆角面板以及有顺序的透明前景层。面板在展平前被截取，并非在最终不透明截图上添加滤镜。
- `LiquidGlassCardRenderer` 使用 SwiftUI 的显式背景、模糊底图、半透明染色、高光、描边、阴影完成合成，再由 `ImageRenderer` 输出原生分辨率图片。
- 本模式是可导出的 **Liquid Glass 风格**，不是系统原生交互式 `.glassEffect`。macOS 26.6.2 / SDK 26.5 上，原生材质的离屏导出实测丢失内容，离屏 HostingView 也不能可靠替代。
- 预览与实际推送使用同一渲染入口。键盘保持 JPEG 限额，AI Mac 保持原有 RGB565/JPEG 编码；玻璃模式不启用固件的纯色播放进度覆盖层。完整图片上传会让固件退出原生播放进度模式。
- 灵犀68 设备外观中的预览解码最终待上传 JPEG，并将完整 142×428 画面按原生比例放入屏幕区域；不再把内部卡片放大、裁掉安全区或额外平滑。活动键盘的歌词直推成功后也同步这一帧。

## 性能与故障边界

无新增定时器、动画循环、屏幕录制权限或可见导出窗口。CIContext 复用，最终图像缓存最多六张，以完整内容及颜色生成键，不以设备 ID 复用图片。每次捕获最多 24 个面板，临时分层内存有上限，文字仍保持原生分辨率。

相同输入复用最终合成图；仅最终成图进行 JPEG 编码。导出失败会结束捕获作用域并重新执行经典渲染，避免发送透明或缺失内容的图像。

## 验证

`LinxDisplaySmokeTests` 覆盖设置迁移、设备范围隔离、两种尺寸/明暗模式、Bambu/正在播放/HA/画板、编码限制、缓存确定性及抛错后作用域恢复。设置 `LINGXI_GLASS_PREVIEW_DIR` 可导出 32 张原生尺寸对照 PNG；示例数据仅在测试目标，不进入应用。

SwiftUI 图像测试需要正常 macOS 图形会话和真正的主线程事件循环（测试入口用 `RunLoop.main.run()`）；限制图形访问的沙箱可能触发经典回退，因此必须核对“玻璃与经典不同”的断言，不能只检查是否有图片。

此为本地开发版，未发布 GitHub。切回经典即可恢复原有设备画面，无需重设设备或刷写固件。
