# C6 与现有 AI 小屏幕的一致性检查

## alpha.18 通用配置、真实帧与可选布局（2026-10-15）

遵循 apple-design 的分组、可读性与就近反馈原则，Mac 继续使用原生 Picker/DatePicker，网页按 XH Multiscreen 的标题与分区层级整理；桌面与手机保留同一功能，不将终端视觉强加给系统控件。浅深色、320/390/1280px 及 200% 网页字号在隔离浏览器中检查，无页面横向溢出。

设备语言、数字风格、休眠及本地打印布局保持设备自有；新数字只用于主数字，任务/实体正文不变。标准打印布局保留图片和详情，超大进度/剩余时间没有空图片框。自动总览同时显示品牌与用户设备名，不以主题颜色区分品牌。天气仍保留已选天空场景，不强制改成橙黑终端。

共享时钟 404 帧、中英/两种数字与静态端点一致，独立 Formlabs 分支 54,704 布局组合回归通过。软件与完整测试通过不等于实体面板、VoiceOver、手机浏览器、OTA 或长期运行验收。

## XH 外观与状态标签修正（2026-10-15）

- 通用分支使用 XH Multiscreen · 多屏灵犀分支的展示命名，不改变 `lingxi-esp32-c6-screen` 协议标识、配置命名空间或 Formlabs 专用分支身份。
- 新增可选“激光橙黑”卡片主题。原有主题序号与默认 Liquid Glass 配色不变；浅色版本使用深橙保证文字对比度，不改变墨水屏的灰阶处理。
- C6 软件页使用原生分组与语义反馈；右侧预览区明确区分软件推送画面和设备实际画面，切换离线模拟时清除旧的软件预览，避免来源误标。
- 新增可选“圆角粗数字”桌面时钟，保留现有翻页钟。几何数字是原创路径，没有提取或内嵌参考网页的 Pixter 字体。电脑预览与固件共用 RGB565 渲染器；圆角样式同步设备色彩校准，原翻页钟像素不变。
- 打印机紧凑状态胶囊原先用字体 ascent/descent 定位中文，用图标框中心定位符号，造成图标偏高。改为按文字实际字形边界居中；长状态按可用宽度调整字号。9 种状态的实际像素检查通过，文字与图标中心误差不超过 1.5 原生像素。
- 全量软件 3,529 项断言、C6 配置/传输/固件/门户回归、共享画面逐像素比较通过。Formlabs 专用分支 54,704 帧布局、原翻页动画及二维码检查通过。这些是测试帧与软件检查，不代表实机画面、长时间运行或 OTA 验收；未自动刷机、重置用户配置或发布。

## 基准与范围

以已有 AI Mac 240×240 彩色卡片为设计基准，不以新简化固件画面取代既有电脑渲染。只在 2.0 分支工作，不改正式 App、用户数据或发布内容。

电脑推送保留现有主题、浅深色、Liquid Glass、摄像头、封面与卡片详情的渲染入口。原生翻页钟仍由 C6 实时计算；本地 HA 状态/静态图、Bambu、Formlabs 和天气保持设备独立运行。

## 设计约束

Mac 延续原生 grouped Form、系统字体与语义色；不是另造一套产品外观。设备屏幕复用已有 ScreenPalette 的背景、正文、卡片、边界和强调色，不重新指定固定品牌色。经典打印机卡片使用 8px 外边距、224px 圆角容器、固定左上设备名、右侧状态胶囊、标题分隔、最多两行任务、细进度条及右侧百分比；底部详情与图片区随可见字段分配空间。

网页沿用系统字体与 16px 正文、14px 辅助字、44px 控件及可见键盘焦点；桌面分组导航，手机同功能单列。常规反馈就近显示，不用弹窗代替状态；未保存资料离页时才确认。

依据：apple-design 的 `layout.md › Visual hierarchy`（分组、对齐、渐进展示）、`typography.md › Ensuring legibility`（清晰字重与字号）、`feedback.md › Best practices`（就近状态）、`settings.md › Task-specific options`（选项留在受影响功能中）。小型硬件屏幕不是 macOS 窗口；字体尺寸按实际 240×240 像素检查，不机械套用桌面字号。

## 离线天气大字可读性修正（2026-10-08）

检查对象是实际 240×240 RGB565 固件帧，不是 macOS 窗口。问题评级：Needs work；High — 温度的 56px 展示用了 16px 正文字形插值放大，边缘发糊。依据 `typography.md › Ensuring legibility` 的可读性原则；不把 Mac 的点大小机械移植到硬件像素。

保留现有天气场景、颜色与层级，不重新设计背景；正文继续 Noto CJK 16px 字库，温度、负号和大尺寸数值改用由原矢量字体生成的 64px、16级抗锯齿字库，缩小至实际字号。小字维持原路径。绘制、测量、换行使用同一份字形度量；6KB 解码缓存不增加，无额外帧缓冲。九种天气的正文安全区域经 RGB565 量化后最小对比度仍 ≥4.5:1。翻页钟数字同时使用高精度字形，保留原布局和动画。

结构：城市 / 分隔线 / 左侧大温度 + 右侧天气图形 / 高低温 / 穿衣 / 洗车 / 更新时间。温度单一强调不再加装饰；电脑在线渲染保持不变。固件仍输出像素帧，不宣称设备实时运行矢量字体引擎。

## 验证边界

alpha.8 继续沿用 apple-design 的布局与可读性原则：HA 图片项独立成格，名称与图片留出安全区；Bambu 实况与任务封面分区、底部对齐，固定标头、两行任务和细进度条保持不变；Formlabs 复用打印机信息层级并保留蓝色品牌强调选项。用户隐藏的详情释放空间，不让空框挤占图片。浅深色与长中英文在真实本地 RGB565 渲染夹具中检查，电脑入口另行导出对照，而不是在截图上贴图片。字体为设备抗锯齿子集，不能宣称与 SF 字体完全相同。

alpha.9 在打印机配置标题与数据源中明确给出品牌文字，保留用户设备名称；切换来源清除旧来源输入。没有新增配色或装饰层，离线画面沿用 alpha.8 布局。模拟大配置与存储失败对应明确的保存结果，不把 500 误报成断网。

必须分别检查电脑成图、实际固件 RGB565 帧缓冲和软件中读取到的设备帧；渲染夹具不等同于物理屏幕验收。离线只有真实存在的数据才能展示，不模拟实时摄像头或电脑专属模块。Liquid Glass 仍由电脑 SwiftUI 渲染；本地经典布局不能宣称为等价原生 Glass。

本轮不自动刷写设备，不读取真实钥匙串秘密，不执行 GitHub 发布。完整软件可用性目标仍需原生窗口与实际设备验证，不能仅凭自动断言标记完成。
