# 多屏灵犀（Lingxi MultiScreen）

一套软件驱动多种桌面屏幕：灵犀68 键盘屏、口袋先知（Rand/0）墨水屏、摘录（Dot）墨水屏、AI Mac 240×240 小屏幕与 AWTRIX NG 点阵屏，并提供 Beta 阶段的 M5Stack StickS3 蓝牙控制器。macOS 26+（Apple 芯片）。

## 2.0 开发测试分支

当前进度：**2.0.0 测试版（build88，2026-10-30）**，开发源码位于 `test/2.0-c6-alpha20`。分支名沿用早期 C6 里程碑，当前已包含完整多设备软件、Pico 管理与中控面板。稳定版继续位于 [`main`](https://github.com/XHFO/lingxi-multiscreen/tree/main) 与 [Releases](https://github.com/XHFO/lingxi-multiscreen/releases)。下方历史界面截图来自 1.5.4，不代表当前测试版。

- **原生中控面板**：设备和数据源混合排列，可添加、隐藏、排序和自定义分组；支持 1×1、2×1、1×2、2×2、2×3 网格，自动回填空位并随窗口适配。
- **设备详情与预览**：侧栏收起时从卡片展开悬浮详情，展开时进入常规详情；持续显示设备预览，Pico、口袋先知、摘录、键盘与 M5 使用对应外壳。
- **共享数据源卡片**：正在播放包含上一曲、播放／暂停、下一曲与封面取色；Home Assistant 可选实体；打印机显示可用实况与任务照片；Cloudflare 和天气以原生图表展示。
- **Pico 完整管理**：图书、字体、笔记、应用、画稿、设备设置、灵犀画板、图片锁屏、固件与备份集成到主程序。内置 Pico `0.40.0-dev71` 和九个 TF 应用包，包安装由用户明确触发。
- **灵犀画板**：复用共享模块和独立轮播，支持原生 16 灰阶、横竖布局、USB 串口画板直传与局域网推送；文件管理保留独立的 TF 传输流程。
- **C6 与既有设备**：保留通用 C6 `2.0.0-alpha.20` 的本地／电脑混合轮换和独立 Formlabs 固件边界，以及口袋先知、摘录、键盘、ESP8266、AWTRIX、M5 的原有能力。
- **系统交互**：原生 Liquid Glass、中英文界面、统一主题与浮层背景；修复卡片圆角残影、配置入口混淆及网格空洞。
- **中控性能**：共用设备与来源列表，按视口刷新设备预览，复用打印机图片；详情遮盖时暂停底层预览。收起侧栏使用系统磨砂玻璃，展开侧栏使用不透明窗口底色，卡片保持半透明。

构建完整测试 App：安装 Xcode Command Line Tools 后运行 `bash scripts/make-app.sh`，输出到 `dist/多屏灵犀 2.0 测试版.app`。最低 macOS 26，Apple 芯片。测试版使用独立 Bundle ID 和 `LinxDisplayBeta2` 数据目录；不会自动导入正式版设备。

构建缓存异常时可使用独立目录：`LINGXI_SWIFT_BUILD_PATH=/private/tmp/lingxi-build bash scripts/make-app.sh`。不要在同一构建目录同时运行多个 Swift 构建。

## 项目来源

新增设备的 Mac 端开发沿用最新 2.0 测试主线，当前公开基线为 `test/2.0-c6-alpha20`。新增设备管理集成到完整主程序，保留已有设备和混合卡片能力；独立工作台包仅用于专项调试。小纸 Pico 的图书、应用、设备设置与画布管理见[使用与开发说明](docs/READ-PICO-MANAGER.md)。

本项目最初基于 [NCZkevin/LinxDisplayWindows](https://github.com/NCZkevin/LinxDisplayWindows) 开发，将其移植为 macOS 原生 SwiftUI 版本，并在此基础上做了大量功能增加与重构（多设备管理、卡片管理、墨水屏画板、按键控制、口袋先知多画板等）。感谢原作者的贡献。

AI Mac 小屏幕并非专有硬件：它使用社区开源的 ESP8266 240×240 Wi-Fi 天气时钟硬件（常见名称为 MG01 / SD2 小电视）。硬件工程可在[立创开源硬件平台](https://oshwhub.com/q21182889/sd2)查看，社区 AI Mac 固件与桥接项目见 [pengchujin/esp8266-ai](https://github.com/pengchujin/esp8266-ai)。多屏灵犀在该类开源硬件上提供独立的定制固件、刷写、设备管理与多屏内容推送能力。

## 1.5.5 更新重点

- 彩色屏幕新增“经典 / Liquid Glass”渲染方式，软件预览与实际推送使用同一张最终图像；墨水屏和 Emoji 壁纸保持经典效果。
- 新增 AWTRIX NG 设备、应用与卡片管理，支持实机 32×8 点阵预览、灵犀文字、Home Assistant 实体、设备轮换和菜单栏快捷操作。
- 新增 Beta 阶段的 M5Stack StickS3 蓝牙控制器：内置完整固件与一键刷写，支持多屏设备、Home Assistant、Vibe Coding、演示翻页、多媒体和自定义 Mac 快捷键。
- StickS3 使用 A/B 键、摇一摇和飞鼠指针交互；蓝牙 HID 可直接发送实体键盘、多媒体和鼠标动作，并提供重新配对引导、蜂鸣器开关、空闲降功耗与屏幕局部刷新。
- 自动轮播可在歌曲切换时优先展示“正在播放”，并自动跳过空闲打印机；多台工作中的打印机依次切换，完成状态保留约 30 分钟。
- 适配 macOS 27 工具链与侧边栏行为，同时继续支持 macOS 26；优化正在播放识别、AI Mac 色彩校准、Home Assistant 图片、打印机名称同步和多设备首帧推送。

## 1.5.4 更新重点

- 新增 AI Mac 240×240 小屏幕正式设备类型，支持系统仪表盘、桌面时钟和自定义图片；最多添加 5 台，每台独立保存 IP、内容模式和推送间隔。
- 软件内明确标注 AI Mac 的开源硬件属性：本体为 ESP8266 240×240 Wi-Fi 天气时钟（MG01 / SD2 小电视），并提供开源硬件工程与社区项目入口。
- 适配 ESP8266 AI Mac 0.8.6 固件：自动使用大端 RGB565 无损帧，并提供适合 ESP8266 内存限制的现代化热点配网页面；设备热点使用带唯一尾号的 `Lingxi-Screen-XXXXXX`，旧固件自动回退 24KB 内 JPEG 兼容推送。
- 设备管理内置定制固件与 USB 刷写流程：刷写前填写 2.4 GHz Wi-Fi，固件与临时配网区一次写入；界面明确提示 ESP8266 不支持 5 GHz/6 GHz，刷写成功后自动等待设备联网、获取 IP 并创建设备档案。密码不写入软件设置，设备成功联网后会擦除临时配网区。
- AI Mac 小屏幕新增彩色多画板：沿用口袋先知的空白新建、模块组合、自动保存、拖拽排序、侧栏显示和自动轮换逻辑，直接输出 240×240 彩色画面，不经过墨水屏灰阶、抖动或插值处理。
- AI Mac 彩色画板完整保留主题强调色、打印机品牌色和封面光晕；正在播放模块可按画板开启智能封面取色，以封面主色生成整板背景、高对比文字、进度色与描边。
- AI Mac 设备管理支持手动添加或扫描当前局域网内已刷写、已联网的小屏幕，无需重新走刷机配网；扫描结果会验证固件身份并按 IP 去重。侧栏按每台设备独立列出卡片管理、全部功能卡片、桌面时钟、画板管理、各块画板与屏幕控制，专辑封面带动态采样彩色光晕。
- AI Mac 现已适配灵犀68 的全部功能卡片，并按 240×240 原生彩色尺寸重新排版；每台小屏幕可独立设置卡片显示/隐藏、拖拽顺序、轮播参与和轮换间隔。桌面时钟也纳入卡片管理，时间和样式由小屏幕固件本机逐秒演算与绘制，软件只负责切换和校时。底层新增统一卡片能力目录，新增卡片或新设备时由能力声明自动接入导航、轮播与渲染。
- 提供 240×240 实时预览、连接测试、立即推送与 1–60 秒自动推送；画面没有变化时不重复发送，降低设备和网络负担。

## 1.5.3 更新重点

- 口袋先知和摘录均新增独立画板管理：每台设备分别创建、自动保存、重命名、排序、隐藏和自动轮播；新画板为空白“未命名”，添加首个模块后自动命名。

- 番茄钟刷新与推送间隔可调，并与电脑端倒计时刻度严格对齐；同时优化 Home Assistant 已选实体刷新、设备管理加载和静态画面缓存复用。

## 1.5.1 更新重点

- Home Assistant 与 Bambu Lab 卡片支持 `camera.*` / `image.*` 静态帧；打印机可同时绑定摄像头和任务封面，并按卡片切换画面来源。
- Bambu Lab 在三类画板中统一为高对比仪表样式，强化设备名、状态、百分比、进度条、双行任务名与数据更新时间。
- 切换 HA/打印机卡片时立即刷新状态；打印机仅请求当前已绑定实体，静态画面异步补推，改善大型 HA 实例的卡顿和延迟。
- 自定义图片新增两种 Pixel 叠排大时钟，支持 Material You 三档动态取色、随壁纸亮暗反色的约 5px 描边、整组缩放、日期开关和更大的位置调整范围。
- 口袋先知支持画板定时自动轮换；灵犀68 可选用 Fn + 旋钮翻页（默认关闭，开启会拦截该键盘的音量控制）。

## 功能特性

- **Home Assistant**：独立实体状态卡片可分别为灵犀68、口袋先知和摘录画板选择显示实体；长名称与长状态自适应排版，每页最多 4 个等高卡片，实体较少时自动调整留白；`camera.*` 与 `image.*` 可抓取当前静态帧显示。连接配置全局共享，访问令牌只保存在本机。
- **Bambu Lab 打印机**：打印机作为独立设备添加，支持多打印机卡片、手动实体映射与解除绑定、字段显示控制、错误告警和打印完成提示；可同时绑定摄像头与任务封面并切换显示。自动匹配需先选择打印状态实体，筛选弹窗可关闭默认筛选以兼容重命名过的设备和实体。
- **Formlabs 打印机**：通过 Formlabs Dashboard 纯云端 API 管理最多 5 台打印机，显示任务名称、进度、层数、打印配置耗材、剩余时间与缩略图；支持 Formlabs 品牌蓝或跟随软件主题，并缓存最近任务避免完成后卡片突然清空。
- **AI Mac 小屏幕（开源硬件）**：设备本体是社区开源的 ESP8266 240×240 Wi-Fi 天气时钟（MG01 / SD2 小电视），多屏灵犀通过局域网驱动并提供定制固件。完整支持灵犀68 的 Codex、千问、番茄钟、系统监控、正在播放、自定义图片、摘录、少数派、Emoji、Home Assistant、Bambu Lab 与 Formlabs 卡片，同时支持彩色多画板和桌面时钟。每台设备独立保存卡片顺序、显示/隐藏、自动轮播、画板和推送设置；画面不做墨水屏黑白/抖动处理。设备管理内置完整性校验、Wi-Fi 预配置与 USB 刷写流程，刷写后自动发现 IP 并添加设备；新固件使用 RGB565 无损帧，旧固件自动使用 JPEG 兼容模式。
- **AWTRIX NG**：可管理多台设备的应用、排序、显示、轮换和设置，并读取实时 32×8 点阵预览。内置灵犀文字和 Home Assistant 卡片，中文内容由本地点阵字库编码，纯英文使用设备原生字体。
- **M5Stack StickS3 控制器（Beta）**：设备管理中内置 ESP32-S3 完整固件与 USB 刷写；控制器可在统一卡片菜单中操作多屏设备、Home Assistant、Vibe Coding、演示翻页、多媒体和自定义快捷键，并支持类似激光笔的飞鼠指针。
- **Liquid Glass 彩屏渲染**：灵犀68 与 AI Mac 可选使用 SwiftUI 合成的玻璃风格最终图像，预览与设备推送保持一致；正在播放的两种强调色均从当前封面采样并自动保证对比度。
- **可扩展卡片框架**：卡片标题、图标、设备支持范围、实时数据依赖与渲染配方由统一能力目录描述；新显示设备声明自己的屏幕族即可复用兼容卡片，打印机卡片位会根据实际设备数量动态出现。
- **侧边栏**：系统标准分栏（NavigationSplitView），分隔条可拖拽调整宽度；可折叠为纯图标窄栏，展开/收起带弹簧动画；设备分组整行点击展开、手风琴式收起；正在播放专辑封面光晕点亮/变暗平滑过渡。
- **实时预览**：右侧键盘预览与键盘实际显示严格一致，窗口任意缩放时预览始终完整显示、绝不裁切。
- **多设备管理**：灵犀68 键盘 / 口袋先知 / 摘录均支持添加多台设备，每台设备独立保存连接信息与画板设置；侧栏按设备分组展示，点开某台设备的分组即操作该设备；设备支持启用/禁用（禁用后侧栏隐藏）、删除需二次确认、允许删光。
- **卡片管理（键盘）**：统一管理各卡片在侧栏的显示、自动轮播的参与与顺序（拖拽排序，顺序同时决定侧栏与轮播顺序，按键盘设备独立）；新设备默认无卡片并提示添加。
- **灵犀画板（键盘）**：自由组合时钟、日期、系统监控（CPU/内存/磁盘/网络/运行时间）、Home Assistant、正在播放、Codex 用量、千问办公额度、番茄钟、自定义文字/图片、少数派推荐等模块，实时预览并推送到键盘屏；Home Assistant 模块按实体数量动态调整占用空间；模块行整条标签栏可点击展开设置；模块上下边距归零即恢复自适应间距。
- **千问办公额度**：进度条按会话最高额度基线计算剩余百分比，显示方式可在「百分比 / 额度数值」间切换；卡片与画板模块均可使用。
- **Codex 额度来源**：可在 Codex 官方数据与 CC Switch 之间切换；CC Switch 模式只读跟随其当前 Codex 供应商和已启用的用量查询规则，不在多屏灵犀内复制或保存密钥。AI Mac 方形彩屏会采用专用高密度额度布局。
- **正在播放模块自适应**：空间充足时竖排大封面；封面会被压小时自动转为横向排布（封面居左、歌名歌手居右，与侧边栏一致）；封面主色生成强调色贯穿进度条与时间文字。
- **Emoji 壁纸（键盘）**：输入几个 emoji 即生成全屏壁纸，三种排列方式（大小混合/网格排列/螺旋），大小与表情间隔可调；螺旋越往中心越紧密、大小变化剧烈；开启底部时间时螺旋中心自动上移，时间区域采用高斯模糊毛玻璃遮罩（深色压暗、浅色轻微压暗+文字淡投影，边缘平滑过渡）。
- **自定义图像模块解耦**：键盘与墨水屏画板互相独立——先知/摘录画板可各自独立选择与替换图片（按各自屏幕比例裁切：先知 1:1、摘录 296:152），互不串扰。
- **自定义图片**：忽略全局顶部安全区，图片铺满整个键盘屏幕显示范围；提供“上方/居中”两种 Pixel 叠排大时钟，四位数字与日期作为一个图层组整体缩放，支持 Material You 自然/鲜艳/表现力三档动态取色、亮暗自适应描边、日期开关与位置微调。
- **摘录语录（键盘）**：语录按分类勾选轮换（名人名言/经典电影台词/诗词名句/谚语俗语），竖排渲染充分利用竖向空间、字号自适应保证完整显示，可手动切上一条/下一条。
- **少数派推荐（键盘）**：展示少数派编辑最新推荐文章（键盘卡片最多三条，推荐优先、不足时以最新文章补齐），标题可点击跳转网页；文章多于三条时可开启「进入本页随机推送三条」；也可作为模块加入三个画板（每个画板独立设置显示条数与随机显示）。
- **番茄钟全局快捷键**：开始/暂停、跳过、重置三个快捷键可在系统范围内自定义绑定（点击录制、Esc 取消、冲突检测），可一键恢复默认组合（带确认提示）。
- **手动翻页快捷键**：全局设置中可为上一页、下一页自定义系统快捷键，无需切回软件即可切换键盘卡片；也可开启灵犀68 Fn + 旋钮翻页，开启后会拦截该键盘的音量调节事件，默认关闭。
- **性能优化**：静态画板减少重复完整渲染，预览与设备推送复用渲染结果；无对应模块时停止无效系统采样，无媒体播放时降低后台查询频率；Home Assistant 只缓存已绑定实体的最后状态，Bambu 卡片切入时只刷新当前打印机已映射实体。
- **更新提醒**：启动自动检查 GitHub 仓库最新版本（6 小时节流），发现新版本在「设置 → 关于」提示并可一键前往下载。
- **口袋先知画板（Rand/0 墨水屏）**：200×200 模块组合，支持深色/亮色底色模式、整体旋转 180°、黑白/4 级灰阶、6 种灰阶算法与 9 种抖动算法，经局域网 WebSocket 推送；可自动推送（内容变化/间隔触发，开启时启动即推一次）。
- **口袋先知多画板**：独立画板管理页支持创建空白画板、自动保存、重命名、删除、拖拽排序、侧边栏显示与轮播参与开关；按设备隔离保存，并可按顺序定时轮换和推送。
- **口袋先知按键控制**：设备按键（短按）可控制自身更新画布 / 切换画板、灵犀68 键盘翻页、摘录切换内容；自研会话启动自动连接、断线自动重连、连接状态实时显示。
- **摘录画板（Dot 墨水屏）**：296×152 模块组合，单列/双列布局（模块可占满整行）、深色/亮色底色、旋转 180°；独立画板管理页支持按设备隔离创建、自动保存、排序、隐藏与自动轮播；支持按官方 image API 推送原始彩色图片由 Dot 服务端处理，也可本地处理后推送。
- **墨水屏显示规范**：口袋先知/摘录两个墨水屏画板上的所有文字统一为纯黑/纯白（无色相），保证墨水屏上文字锐利清晰；正在播放封面带 2px 黑色描边，避免浅色封面与背景融合。
- **系统卡片**：番茄钟、系统监控、Codex 用量、千问办公额度、自定义图片、正在播放等完整键盘卡片。
- **多屏整合**：任一画板含 Codex/千问额度模块时统一调取一次用量数据供各功能共享；专辑封面变化/时间变化自动触发推送。

## 安装

1. 从 [Releases 页面](https://github.com/XHFO/lingxi-multiscreen/releases) 下载最新发布包（`lingxi-multiscreen-<版本>.dmg`），打开磁盘映像后把 `多屏灵犀.app` 拖到 `Applications`。
2. 首次打开若提示「无法验证开发者」：右键点击图标 → 选「打开」→ 再点「打开」；或在终端执行
   `xattr -dr com.apple.quarantine /Applications/多屏灵犀.app`
3. 要求：macOS 26 及以上、Apple 芯片（M1 及以上）。

## 设备配置

全新安装首次打开软件会进入「开始使用」引导页，初始设备列表为空，按提示进入「设备管理」添加你的设备。正式发布包不包含开发或测试期间的设备、地址、令牌、实体选择及历史图片；已有用户覆盖升级时仍会保留自己电脑上的配置。灵犀68、口袋先知和摘录的连接信息按设备独立记录，Home Assistant 连接由所有相关卡片全局共享：

### 灵犀68 键盘

在「设备管理」添加灵犀68 设备并填写设备 IP（同一局域网），软件自动补全推送地址 `http://<IP>/image/upload` 并推送到键盘屏。多把键盘时，可在「设置 → 灵犀68 屏幕控制」中指定菜单栏快捷切换（切换显示内容 / 立即推送）控制哪一台键盘，默认跟随当前活动键盘。

### 口袋先知（Rand/0）

1. 在「设备管理」添加口袋先知设备并填写设备 IP（同一局域网）；输入框旁的感叹号可查看官方显示模式文档。
2. 建议开启「深色/亮色底色」中的亮色模式，避免墨水屏长时间黑底。
3. 推送：手动点「推送到 Rand/0 设备」，或开启「自动推送」（内容变化立即推、无变化按间隔推，开启时启动即推一次）。
4. 按键控制：在「按键控制」页选择设备按键的控制目标（自身更新画布/切换画板、灵犀68 键盘翻页、摘录切换内容）。

### 摘录（Dot）

1. 在 Dot App 中获取设备的 API Key（`dot_app_...`）与设备序列号，填入「设备管理」摘录设备的对应输入框（感叹号可跳转官方获取说明）。
2. 在 Dot App 的 Content Studio 中，把「图片 API」加入设备的卡片循环（Loop），否则推送不会上屏。
3. 「推送原始彩色图片」默认开启：直接推送彩色原图，由 Dot 服务端按所选「服务端抖动方式/抖动核」转换；关闭则用本地 4 级灰阶 + 抖动处理后再推。
4. 设备离线或休眠时，内容会先存到服务端，设备下次刷新时显示。

## 使用要点

- 画板模块：在「当前组合」添加/删除模块，行内点右侧箭头可展开该模块设置；模块行可拖拽排序（各画板独立）。
- 卡片管理：灵犀68 与每台 AI Mac 小屏幕都有独立「卡片管理」页面；拖拽排序决定该设备的侧栏顺序，每张卡片可开关侧栏显示与轮播参与，行尾快捷开关可一键启停该设备的自动轮播。
- 摘录画板双列布局：在模块行点 ⇄ 图标让该模块占满整行。
- 两个独立画板（先知/摘录）均为「主内容 + 右侧边栏」双栏布局；先知画板右侧为纵向预览（处理前/处理后）。
- 底色模式（先知/摘录）：深色/亮色手动切换，不随电脑或软件主题同步。
- 摘录语录：在「摘录语录」页勾选要轮换的分类；切换分类后立即回到自动轮换。
- 少数派推荐画板模块：模块展开设置里可调显示条数（1–6）与随机显示开关（三个画板各自独立）。
- 侧栏：设备分组默认全部收起，点标题整行展开（展开一台自动收起其余）；可收起为窄图标栏（只显示设备图标 + 正在播放封面）。
- 正在播放卡片：底部时间/日期可自定义格式与字号，也可隐藏（封面居中、信息贴底）。

## 隐私说明

- 所有配置（设备 IP、API Key、图片等）仅保存在本机，随软件发送的压缩包不含任何本机配置与凭据。
- 摘录推送会向 dot.mindreset.tech 上传你推送的图片内容；口袋先知推送仅在本机局域网内进行。
- 本发布版本已移除打包机器上的个人信息（设备 IP、API Key、序列号、历史图片与缓存）。
